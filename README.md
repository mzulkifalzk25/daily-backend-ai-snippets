# Daily Backend / AI Snippets

Small, runnable Django, DRF, FastAPI and LLM-agent snippets. Each one is explained in its own folder and posted alongside a [LinkedIn](https://linkedin.com/in/mzulkifalzk25) post.

## Folder convention

```
YYYY-MM-DD-short-topic/
├── README.md   # what it is, why it matters, how to run it
└── ...         # the code
```

## How this repo works

Each entry lives in its own `YYYY-MM-DD-short-topic/` folder (see the convention above) and gets a row in the index table below. To add a new entry, copy `_template/README.md` into your new folder, fill it in, and add the code alongside it.
